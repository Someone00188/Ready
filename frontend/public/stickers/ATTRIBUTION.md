# Sticker Attribution

Profile stickers in this project use graphics from **Twemoji**
(https://github.com/jdecked/twemoji), maintained by jdecked and
originally created by Twitter, Inc.

SVG files were downloaded from the public repository and optimized
with SVGO (lossless compression, no visual changes) before being
included in this project's `/public/stickers/` directory.
